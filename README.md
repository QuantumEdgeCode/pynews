# Top News URLs

一个每小时运行一次的新闻 URL 采集器，覆盖 15 个新闻源。URL 数组保存在 Git 仓库的 `data/` 目录下，每行一条 URL，方便后续采集时通过 diff 直接看出新增内容。Dataverse 上的全文发布版本属于历史存档。
